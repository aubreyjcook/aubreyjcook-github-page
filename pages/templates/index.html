Templates

Starting points for new pages, kept in two flavours: hand-written markup, and markup built from Tailwind utilities. All four use the shared stylesheet and terminal chrome, so a page copied from any of them matches the rest of the site.

From scratch

Minimal shells. Copy one and add markup.

  • template-01 Bare header, nav, main, footer. Nothing else.
  • template-02 Adds the name and title block, and a full primary nav.
  • template-03 Centred nav variant with the footer quote.

With Tailwind

The full page shell used by the live site, including the skip link, sticky header, mobile nav, and footer.

  • template-04 Complete shell for a page two directories below the site root.

There is also a single-file starter at pages/tailwind-template.html.

Relative paths

These files sit three levels below the site root, so every reference climbs three: ../../../styles/site.css. A page copied from a template into pages/ is only two levels deep and needs one ../ removed. This is the mistake these templates originally shipped with.
